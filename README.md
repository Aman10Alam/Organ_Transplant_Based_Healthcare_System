Organ Transplantation Blockchain Platform
A secure, transparent, and scalable Web3 application for tracking organ donations and transplants using Hyperledger Fabric, React, and Express.js.

Features
Blockchain Ledger: Utilizes Hyperledger Fabric to securely record and track organ donation and transplant events, enhancing trust and accountability.

Smart Contracts: Automates donor-recipient matching and ensures compliance with medical and ethical guidelines. All data is stored immutably on the blockchain.

User Interface: Built with React and Express.js for a responsive, user-friendly experience.

Performance Tested:

Simulated up to 10,000 transactions with 5 workers to confirm scalability under heavy load.

Evaluated system performance by varying worker count from 10 to 100 with 1,000 transactions, optimizing transaction speed and network efficiency.

Tech Stack
Blockchain: Hyperledger Fabric
Frontend: React.js
Backend: Express.js, Node.js
Database: Ledger
Cloud/DevOps: AWS
